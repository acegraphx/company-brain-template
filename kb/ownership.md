# Vlastníci oblastí

Oblast a GitHub tým, který ji schvaluje. Jsou to role, ne osobní údaje. Každý tým musí být v `.github/CODEOWNERS`.

| Oblast | Tým |
|---|---|
| architektura (kb/architecture/) | @ORG/tech-leads |
| rozhodnutí (kb/decisions/) | @ORG/tech-leads |
| runbooky (kb/runbooks/) | @ORG/tech-leads |
| produkt (kb/product/) | @ORG/product-owners |
| zakázky (kb/projects/) | @ORG/project-leads |
| pravidla a nástroje (AGENTS.md, SCHEMA.md, tools/, .github/) | @ORG/brain-maintainers |
